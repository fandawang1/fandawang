# 大模型对话助手

基于 Python + Gradio 的大模型对话助手，支持多轮对话、会话管理、角色化助手、上下文压缩、结构化输出和幻觉检测等功能。

## ✨ 功能特性

### 核心对话功能
- 💬 **多轮对话**：支持流式响应，实时显示模型输出
- 📝 **Markdown 渲染**：支持代码块、列表、表格等富文本格式
- 🔄 **上下文管理**：自动携带历史消息，支持长对话上下文压缩

### 对话管理功能
- 📋 **会话列表**：左侧展示所有会话，支持切换、新建、删除
- 🆕 **新建对话**：一键创建新会话，自动切换
- 🗑️ **删除对话**：支持删除单个会话
- 🔄 **刷新列表**：手动刷新会话列表，显示最新标题
- 🏷️ **智能命名**：新建会话显示"新对话"，发送首条消息后自动提取前 10 字作为标题，重复时自动添加数字后缀

### 模型配置
- 🎯 **多模型支持**：支持 DeepSeek 和 千问（Qwen）模型
- 🔧 **参数调节**：Temperature、Top P、Max Tokens 实时可调
- ⚙️ **配置管理**：通过 `.env` 文件管理所有配置

### 高级功能
- 🎭 **角色化助手**：6 种预设角色（默认助手、技术专家、辅导老师、文案作家、数据分析专家、翻译官）
- 📐 **结构化输出**：支持自然语言、JSON、清单、Markdown 格式
- 🧠 **上下文压缩**：长对话时自动总结历史，避免超出上下文限制，使用当前会话模型
- ⚠️ **幻觉检测**：基础事实核查机制，检测回答中的虚构信息，使用当前会话模型

## 🚀 快速开始

### 环境要求
- Python 3.10+
- 硅基流动（SiliconFlow）API Key

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置环境变量

1. 复制 `.env.example` 为 `.env`：

```bash
# Linux / macOS
cp .env.example .env

# Windows (PowerShell / CMD)
copy .env.example .env
```

2. 编辑 `.env` 文件，填入你的 API Key：
```env
# 大模型 API 配置（硅基流动）
LLM_API_KEY=your-siliconflow-api-key-here
LLM_BASE_URL=https://api.siliconflow.cn/v1

# 默认模型提供商：deepseek 或 qwen
LLM_PROVIDER=deepseek

# 生成参数
LLM_TEMPERATURE=0.3
LLM_TOP_P=0.3
LLM_MAX_TOKENS=2048
```

### 启动应用

```bash
python main.py
```

应用将启动在 `http://localhost:7860`

## 🔧 配置说明

### 环境变量

| 变量名 | 说明 | 默认值 |
|--------|------|--------|
| `LLM_API_KEY` | 硅基流动 API 密钥 | 必填 |
| `LLM_BASE_URL` | API 基础地址 | `https://api.siliconflow.cn/v1` |
| `LLM_PROVIDER` | 默认模型提供商 | `deepseek` |
| `LLM_MODEL` | 模型名称（可选） | 按提供商自动映射 |
| `LLM_TEMPERATURE` | 采样温度（0.0-2.0） | `0.3` |
| `LLM_TOP_P` | 核采样参数（0.0-1.0） | `0.3` |
| `LLM_MAX_TOKENS` | 最大生成 token 数 | `2048` |

### 模型映射

| 提供商 | 默认模型 | 基础地址 |
|--------|----------|----------|
| DeepSeek | `deepseek-ai/DeepSeek-V3` | `https://api.siliconflow.cn/v1` |
| Qwen | `Qwen/Qwen2.5-72B-Instruct` | `https://api.siliconflow.cn/v1` |

## 🎭 角色模板

系统预设 5 种角色，每种角色有独立的系统提示词：

| 角色 | 名称 | 描述 |
|------|------|------|
| `default` | 默认助手 | 友好的通用对话助手 |
| `tech` | 技术专家 | 精通编程和技术问题 |
| `teacher` | 辅导老师 | 耐心的知识传授者 |
| `writer` | 文案作家 | 擅长写作和文案创作 |
| `analyst` | 数据分析专家 | 擅长数据分析和解读 |
| `translator` | 翻译官 | 精通把英语转换为中文 |

## 📐 输出格式

支持 4 种输出格式：

| 格式 | 说明 |
|------|------|
| `text` | 自然语言（默认） |
| `json` | JSON 格式，自动验证 |
| `list` | 清单格式 |
| `markdown` | Markdown 格式，支持标题、加粗、代码块、列表等语法 |

## 🧠 上下文压缩

当对话消息超过 15 条时，系统自动：
1. 提取历史对话的关键信息
2. 生成简洁的摘要（不超过 200 字）
3. 保留最近 10 条完整消息
4. 将摘要作为系统消息插入上下文
5. 使用当前会话的模型提供商进行压缩

---

## ⚠️ 幻觉检测

系统使用大模型检测回答中的虚构信息：
- 检测不符合常识的内容
- 识别可能的虚构信息
- 标记未经验证的断言
- 检测到幻觉时显示警告提示
- 使用当前会话的模型提供商进行检测

## 🏷️ 会话命名规则

| 场景 | 命名规则 | 示例 |
|------|---------|------|
| 新建会话 | 临时名称"新对话" | `新对话` |
| 首次发送消息 | 提取消息内容前 10 字 | `什么是人工智能` |
| 消息超过 10 字 | 截取前 10 字并添加省略号 | `请帮我解释一下什么是机...` |
| 标题重复 | 自动添加数字后缀 | `什么是Python (1)` |
